Plasmid

GenBank (.gb), SnapGene (.dna) or FASTA. Files stay on this computer. A plasmid with no annotation can name its start codon in the FASTA header (see Paste a sequence).

For a FASTA plasmid without annotation, write the start codon in the header: start=5307 is the position of the A of the ATG, and mcs=5305-5380 (optional) is the cloning region. Positions count from 1 on the strand as written.

      Why are some sites unavailable?
        Tags and linkers

        Built onto your protein as extra residues. Leave them out if your sequence already carries them.

        C-terminus

        One is the usual choice, the host's most used stop codon. Two are sometimes used to guard against read-through.

        Extra bases for ordering

        Enzymes cut poorly at the very end of a DNA fragment, so a synthetic fragment needs a few bases beyond each site. They are cut away and never reach your plasmid. Six on each side is a common guideline; some enzymes need fewer.

        GC and repeat limits

        After choosing codons, p2d swaps synonymous codons to bring the DNA inside these limits, without ever adding a cloning site. The starting values are the host profile's defaults and have not been checked against a reference, so set the ones your synthesis or cloning work needs. Anything the protein forces stays and is reported.

        Codon strategy

        Leave empty for a reproducible default. The same inputs always give the same DNA.

        Design many proteins at once

        Uses the vector, start codon, sites, C-terminus, tags, host, limits and extra bases chosen above for every protein. Paste FASTA text, or load a file. A protein that cannot be cloned is reported by name and the rest carry on.

        Runs entirely in this tab. Python itself is downloaded once and executed by your browser, so nothing you paste or upload is sent anywhere — there is no server to send it to.
